## Generating 10X multiome test datasets (named toydataset)

- Conda environment: requirements.txt
- Datasets generated by multiome_toy.sh
    - toy_atac.tsv (from atac_fragments.tsv.gz)
    - toy_atac.tsv.gz
    - toy_atac.tsv.gz.tbi
    - toy_peaks.bed (from atac_peaks.bed calculated by ZINBA)
    - toy_barcodes.csv (from per_barcode_matrix.csv)
- Datasets generated by GEX.R
    - toy_matrix.rds (from filtered_bc_matrix.h5)

## Workflow

- Toy dataset generation (multiome_toy.sh is embedded)

```bash
conda activate ../env && Rscript -e "rmarkdown::render('tenx_process/GEX.R')"
```

- Annotation construction

```bash
Rscript -e "rmarkdown::render('tenx_process/annotation_ensdb.Rmd')"
```

- Seurat object construction (optional)

```bash
Rscript -e "rmarkdown::render('tenx_process/toy_seurat.Rmd')"
```
